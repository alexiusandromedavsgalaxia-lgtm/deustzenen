# Deustzenen™ — Especificación viva

## Qué es

Deustzenen™ es una lengua construida/reconstruida a partir de un corpus experimental. Su descripción debe distinguir cuidadosamente:

- **ortografía**: cómo se escribe;
- **correspondencia**: qué cambios observamos entre escritura y salida registrada;
- **fonología**: qué reglas generales pueden explicar esas correspondencias;
- **morfología**: cómo se forman las palabras;
- **sintaxis**: cómo se combinan;
- **semántica**: qué significan.

## Regla fundacional

> El corpus manda.

No se corrigen las formas para hacerlas parecer alemán, español o ninguna otra lengua.

## Estado actual

### CONFIRMED
- `ß → s`
- `ßß → b`
- `saßßen → seben`
- Las correspondencias documentadas en `corpus/confirmed.md`.

### HYPOTHESIS
- Un posible sistema SVO.
- Segmentación morfológica provisional.
- Valores fonéticos todavía incompletos.

### UNKNOWN
- significado completo del léxico;
- paradigma verbal;
- género;
- número;
- caso;
- inventario IPA definitivo;
- acento;
- sintaxis completa.

## Convención editorial

Toda nueva regla debe indicar su estado. Cuando aparezca evidencia contradictoria, se conserva el dato histórico y se rebaja la generalización; nunca se borra el corpus para salvar una teoría.
