# Sintaxis

Estado: **HYPOTHESIS**.

La sintaxis se reconstruirá después de separar correspondencias fonológicas de correspondencias gramaticales.

## Preguntas abiertas

- orden de constituyentes
- posición de determinantes
- negación
- interrogación
- subordinación
- coordinación
- posición de modificadores
- concordancia
- valencia verbal

## Procedimiento

Para cada hipótesis:
1. localizar estructuras repetidas;
2. buscar pares mínimos o casi mínimos;
3. comprobar distribución;
4. comparar con todas las frases disponibles;
5. marcar CONFIRMED, HYPOTHESIS o UNKNOWN.
