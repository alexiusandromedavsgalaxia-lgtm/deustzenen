# Gramática deustzenen

Estado: EN CONSTRUCCIÓN.

La gramática no se inventa a partir del alemán. Se extraerá del corpus.

## Método
1. Segmentar las frases.
2. Identificar formas repetidas.
3. Comparar posiciones y funciones.
4. Proponer análisis.
5. Marcar cada análisis como HYPOTHESIS hasta confirmación.

## Primeras observaciones

Las formas repetidas del corpus incluyen **einen**, **fiül**, **siftft/sizft/siftze**, **zut**, **laddär/laddâr** y otras. La mera repetición no demuestra categoría gramatical.

No hay todavía suficiente evidencia para afirmar:
- género;
- casos;
- conjugación;
- plural;
- orden sintáctico;
- artículos;
- negación;
- sistema verbal.

Estas categorías quedan ABIERTAS.
