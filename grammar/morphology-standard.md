# Standard Morphology

## Nouns

Common:
bok → boken → bokar → bokarna

Neuter:
hus → huset → hus → husna

## Adjectives

stor → stort → stora
ung → ungt → unga

## Regular verb architecture

läs-:
- infinitive: att läsa
- present: läs
- past: läste
- supine: läst
- imperative: läs

spel-:
- infinitive: att spela
- present: spelar
- past: spelte
- supine: spelt

The historical corpus does not have to obey this architecture.

## Derivation

- -er = agent
- -heit = abstract noun
- -ig = adjective
- -ning = event/result noun
- -chen = diminutive
- -skap = collective/relationship noun

Examples:
skriv-er = writer
fri-heit = freedom
kraft-ig = powerful
bygg-ning = building
hus-chen = little house
vän-skap = friendship

## Pronouns

Subject:
ik, du, he, et, wi, ir, se

Object:
mik, dik, hem, et, uns, iw, sen

Possessive:
min, din, sin, sit, unser, iwer, ir

## Case

Modern standard has no productive noun case apart from possessive -s.
Historical case-like forms remain unresolved.
