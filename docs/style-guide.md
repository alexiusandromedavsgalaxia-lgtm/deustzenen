# Deustzenen Style Guide

## Sound

Aim for a Germanic consonant backbone with a distinctly northern vowel palette.

## Spelling

Prefer:
ä ö å y
sj sk ch
w j
Germanic compounds
occasional historical ß

Avoid turning every word into a direct Swedish copy.

## Word creation

1. Prefer inherited-looking Germanic roots.
2. Use northern vowel shapes where they improve the identity.
3. Prefer short native roots.
4. Build new concepts with compounds.
5. Mark uncertain historical forms as HYPOTHESIS or PENDING.
6. Mark deliberate modern additions as CONSTRUCTED.

## Examples

good native-looking:
jernbane
vinterdag
språkbok
morgonröd

too transparent as Swedish:
ren svensk vocabulary copied without adaptation

## Tone

Deustzenen should feel like a Germanic cousin that spent too long in Scandinavia and came back with an accent.
