# Corpus Deustzenen

Este directorio distingue entre datos y análisis.

## CONFIRMED
La escritura y pronunciación han sido proporcionadas/confirmadas.

## PENDING
Hay escritura, pero falta pronunciación confirmada.

## HYPOTHESIS
Existe una interpretación provisional.

## Regla de corpus

Nunca modificar una frase histórica para hacerla encajar con una regla nueva. Si aparece una excepción, se conserva y se investiga.
