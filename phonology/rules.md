# Reglas fonológicas

## Confirmadas

### RULE 001

- INPUT: ß
- OUTPUT: s
- STATUS: CONFIRMED

### RULE 002

- INPUT: ßß
- OUTPUT: b
- STATUS: CONFIRMED

Ejemplo documentado:

`saßßen → seben`

## Pendientes

No se deben convertir todavía en reglas generales patrones como:

- cambios entre a / ä / e / ë / i / ö / ü / u
- transformaciones de finales
- comportamiento de grupos como ßh
- cambios consonánticos como `latzerot → lasrot`

Esos patrones son observaciones o hipótesis hasta disponer de más evidencia.
