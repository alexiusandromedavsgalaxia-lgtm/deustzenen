# Verb System

Status: CONSTRUCTED standard.

Deustzenen verbs have no person agreement.

## Regular pattern

Infinitive: att + infinitive
Present: present stem/form
Past: -de or -te
Supine: -t
Perfect: ha + supine

Example: spela

att spela
spelar
spelade
spelt
ha spelt

Example: lära

att lära
lär
lärde
lärt
ha lärt

## Strong verbs

A small core of frequent verbs keeps vowel alternations.

vara → er → var → vart
komma → kommer → kom → kommet
skriva → skriver → skrev → skrivet
gå → går → gick → gått

These forms are CONSTRUCTED standard paradigms.

## Modal verbs

kunna → kan → kunde
vilja → vill → ville
måste → måste → måste
skola → skal → skulle

Modal + bare infinitive:
Ik kan läsa.
Du vill komma.
Se skal skriva.

## Imperative

Use the bare present stem:
kom!
läs!
skriv!
gå!
