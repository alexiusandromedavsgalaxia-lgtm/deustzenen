# Metodología de reconstrucción

Deustzenen™ se desarrolla como una lengua construida basada en datos.

## Pipeline

`ORTHOGRAPHY → CORPUS → CORRESPONDENCES → PHONOLOGY → MORPHOLOGY → SYNTAX`

### 1. Ortografía
Registrar exactamente cada grafía.

### 2. Correspondencias
Comparar grafía y pronunciación palabra por palabra.

### 3. Fonología
Solo elevar una correspondencia a regla cuando haya ejemplos independientes suficientes.

### 4. Morfología
Buscar alternancias dentro de palabras y formas recurrentes.

### 5. Sintaxis
Buscar patrones de orden y distribución.

### 6. Semántica
No asignar significados sin evidencia contextual.

## Convenciones

- CONFIRMED = dato seguro.
- HYPOTHESIS = análisis provisional.
- UNKNOWN = todavía no sabemos.
