# Overview

## Identidad

Deustzenen™ comenzó como una transformación experimental de alemán, pero el objetivo es convertirlo en una lengua autónoma.

La estética germánica puede mantenerse, mientras que gramática, fonología, morfología, léxico y pronunciación evolucionan independientemente.

**DEUSTZENEN™ ≠ alemán deformado.**

## Estados de evidencia

- **CONFIRMED** — escritura y pronunciación proporcionadas/confirmadas.
- **PENDING** — existe escritura, pero no pronunciación confirmada.
- **HYPOTHESIS** — análisis o pronunciación propuestos, todavía no confirmados.

## Regla de oro

1. Guardar la escritura EXACTAMENTE.
2. Registrar la pronunciación.
3. Compararla con frases anteriores.
4. Buscar patrones.
5. No convertir automáticamente un patrón en regla.
6. Formular una hipótesis cuando haya suficientes ejemplos.
7. Probarla contra todo el corpus.
8. Confirmarla solo si funciona.
9. Si falla, mantenerla como hipótesis o dividirla en varias reglas.
